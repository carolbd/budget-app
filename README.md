# budget-app
# Il Mio Budget — PWA

## File inclusi
- `index.html` — l'app completa
- `manifest.json` — configurazione PWA (nome, icona, colori)
- `sw.js` — service worker per funzionamento offline

## Come pubblicare su Vercel

### 1. Crea repository su GitHub
1. Vai su github.com → "New repository"
2. Nome: `budget-app` — Pubblico — Crea
3. Carica i 3 file trascinandoli nella pagina

### 2. Pubblica su Vercel
1. Vai su vercel.com → "Add New Project"
2. Connetti GitHub e scegli il repo `budget-app`
3. Clicca Deploy — in 30 secondi hai il link

### 3. Installa sul iPhone/iPad
1. Apri Safari (non Chrome!)
2. Vai sul link es. budget-app.vercel.app
3. Tocca icona Condividi (quadrato con freccia)
4. "Aggiungi a schermata Home"
5. Dai un nome → Aggiungi

L'app appare sulla home come una normale app.
